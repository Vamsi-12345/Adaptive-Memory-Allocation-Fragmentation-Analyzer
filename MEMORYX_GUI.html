FCFS Scheduling

Processes execute in order of arrival. Once a process starts, it runs until completion. This is a non-preemptive scheduling algorithm.

Priority Scheduling

The available process with the highest priority executes. A newly arrived higher-priority process can interrupt the currently running process. This implementation uses preemptive scheduling.
