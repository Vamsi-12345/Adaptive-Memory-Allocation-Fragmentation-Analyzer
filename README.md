# Adaptive Memory Allocation & Fragmentation Analyzer

## 📌 Overview

A C++-based simulation project that analyzes and compares memory allocation strategies under different workloads.

The system uses **artificial memory** to safely simulate memory allocation, de-allocation, and fragmentation without affecting actual RAM.

## ✨ Features

- Artificial/Virtual Memory Simulation
- First Fit, Best Fit & Worst Fit
- Memory Allocation & De-allocation
- Memory Block Splitting & Merging
- Internal & External Fragmentation Analysis
- Memory Utilization & Allocation Failure Analysis
- Adaptive Engine for Strategy Selection

## 🧠 DSA & C++ Concepts

**DSA:**  
Arrays/Vectors, Linked Lists, Queues, Priority Queue/Heap, Hashing, Searching, Sorting

**C++:**  
OOP, STL, File Handling, Exception Handling, Inheritance & Polymorphism
